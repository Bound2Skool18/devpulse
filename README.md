# DevPulse 🚀

A team productivity and standup tracker built for engineering teams.

## 📖 Overview

DevPulse helps engineering teams coordinate daily work through async standups, 
ticket tracking, GitHub PR integration, and real-time notifications. Built as 
a full-stack application to mirror the workflows of modern software teams.

## ✨ Features

- 🔐 JWT-based authentication with role-based access (Engineer / Tech Lead / Manager)
- 🗣️ Daily standup submission and team feed
- 📌 Drag-and-drop Kanban board for ticket management
- 🔗 GitHub OAuth integration for live PR data
- 🔔 Real-time notifications via WebSockets
- 📊 Team productivity analytics dashboard
- 📟 On-call rotation scheduling

## 🛠️ Tech Stack

**Frontend:** React, TypeScript, Tailwind CSS, Vite  
**Backend:** Node.js, Express, Prisma ORM  
**Database:** PostgreSQL  
**Real-time:** Socket.io  
**Testing:** Jest, Supertest, Playwright  
**DevOps:** Docker, GitHub Actions  
**Hosting:** Vercel (frontend), Railway (backend), Neon (database)
